# BrandOS Documentation Index

This directory contains the operating knowledge for BrandOS. Read it as the map of the repository.

## Primary Areas

- `standards/`: contribution, writing, naming, documentation, and review rules
- `foundation/`: repository purpose, principles, glossary, roadmap, and release boundaries
- `product/`: completed v0.2 product core, domains, workflows, roles, and objects
- `brand/`: brand strategy, voice, positioning, and taxonomy
- `design/`: future v0.3 design system foundations
- `ai/`: future v0.4 AI agents, prompts, memory, and evaluation contracts
- `architecture/`: future v0.5 architecture decision space
- `infrastructure/`: future v0.6 operational baseline
- `security/`: security, privacy, risk, and compliance baseline
- `operations/`: release, quality, support, and planning workflow
- `decisions/`: ADRs and decision logs
- `templates/`: reusable repository templates

## Rule

When a new durable decision is made, add it to the relevant documentation area and link it from an index.
