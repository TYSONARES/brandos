# Architecture v0.5 Scope

## Goal

Define repository-level system boundaries before runtime implementation begins.

## In Scope

- Service boundaries
- API boundaries
- Data entity boundaries
- Event boundaries
- Frontend and backend responsibilities
- Auth and permission expectations
- Integration constraints
- Testing boundaries

## Out Of Scope

- Cloud provider selection
- Deployment architecture
- Database engine selection
- Runtime agent orchestration implementation
- Production code

## Definition Of Done

- Service Boundary schema and fixture exist.
- Service boundary set maps core domains to ownership boundaries.
- API Boundary schema and fixture exist.
- Data Entity schema and fixture exist.
- API and data entity sets map to valid service boundaries.
- Event, auth, integration, and test strategy contracts exist.
- Architecture docs map back to Product Core and AI Agents.
- Runtime choices remain deferred to later releases.
