# Token Set

## Purpose

The v0.3 token set defines reusable visual decisions for BrandOS product workflows.

## Token Files

- `fixtures/tokens/color.json`
- `fixtures/tokens/typography.json`
- `fixtures/tokens/spacing.json`
- `fixtures/tokens/radius.json`
- `fixtures/tokens/shadow.json`
- `fixtures/tokens/motion.json`

## Rules

- Token names must be stable and descriptive.
- Color tokens must never be the only way status is communicated.
- Spacing tokens should keep dense operational screens readable.
- Motion tokens should clarify state changes, not decorate the interface.
- Radius should stay restrained; standard cards and panels use `radius.2` at most.

## Product Core Mapping

Tokens must support Product Core workflows such as review, approval, claim verification, and context pack generation.
