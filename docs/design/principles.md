# Principles

## Design Principles

- Product clarity before decoration.
- Every component should support a Product Core object, workflow, or review moment.
- Status must be visible through text and structure, not color alone.
- Dense operational screens should remain scannable and calm.
- Accessibility is a release requirement, not a late polish pass.

## Product Fit

BrandOS is an operating system for brand intelligence. Its interface should feel structured, trustworthy,
and efficient for repeated strategic work.
