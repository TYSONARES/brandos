# Productization Runtime v1.9 Scope

## Status

Scope started.

## Purpose

Productization Runtime v1.9 turns the released BrandOS v1.0.0 baseline into the first product-facing
runtime track. It defines how BrandOS moves from repository-backed Studio evidence into usable product
surfaces, packaged operator flows, and product-ready runtime checkpoints without skipping traceability.

## Entry Criteria

- BrandOS v1.0.0 is released from `main`.
- Release Governance v1.8 is closed.
- The productization branch starts from the released `brandos-v1.0.0` baseline.
- Runtime changes remain dependency-free unless a new ADR explicitly approves a dependency.
- Any production, database, authentication, or external AI execution work remains out of scope until
  separately approved.

## Planned Packages

1. Productization Runtime Scope
2. Product Surface Inventory
3. Product Workflow Prioritization
4. Studio Product Mode
5. Product Evidence Pack
6. Productization Aggregate Summary
7. Productization Final Closure

## In Scope

- Product-facing scope and package boundaries after BrandOS v1.0.0.
- Usable Studio surfaces that map to Product Core, workflow, and release evidence.
- Product workflow prioritization based on repository-backed contracts.
- Evidence packs that show which product decisions, fixtures, components, and runtime outputs support
  each shipped surface.
- Release notes and closure checklists for every productization package.

## Out of Scope

- Production deployment execution.
- Database integration.
- Authentication runtime.
- External billing, CRM, analytics, or customer support integrations.
- Live AI model execution.
- Hosted infrastructure provisioning.
- Automatic GitHub release publication.

## Quality Gates

- `npm run check:docs`
- `npm run check:development`
- `npm run check:development-release`
- `npm run check:productization-runtime`
- `npm run check:all`

## Completion Criteria

- Every planned package has an iteration document.
- Release notes and closure checklists exist for aggregate and final closure packages.
- The development index, decision index, changelog, and manifest reflect Productization Runtime v1.9.
- `check:productization-runtime` validates required v1.9 documents and snippets.
- Full repository validation passes before final closure.
