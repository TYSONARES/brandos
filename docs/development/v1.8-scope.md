# Release Governance v1.8 Scope

## Status

Scope started.

## Purpose

Release Governance v1.8 turns completed Mainline Release Readiness into repository-backed release
governance. It defines how BrandOS records release decisions, approval evidence, publication planning,
rollback readiness, and post-release audit signals before any release is treated as complete.

## Entry Criteria

- Development Ready v1.0 is complete.
- Repository Collaboration Workflow v1.6 is closed.
- Mainline Release Readiness v1.7 is closed.
- The active branch has passed full repository validation before the cycle begins.
- Main branch changes still require explicit operator approval.

## Planned Packages

1. Release Decision Record
2. Release Approval Evidence
3. Publication Plan
4. Rollback Readiness
5. Post-Release Audit Summary
6. Release Governance Aggregate Summary
7. Release Governance Final Closure

## In Scope

- Repository-backed release decision criteria.
- Approval evidence required before publication.
- Publication plan evidence that does not execute deployment.
- Rollback readiness and recovery criteria.
- Post-release audit signals and closure evidence.
- Studio and fixture surfaces only when required by package-level iteration scope.

## Out of Scope

- Production deployment execution.
- Automatic GitHub release creation.
- Main branch merge automation.
- External release automation.
- Database, authentication, or secrets runtime.
- Live AI model execution.
- Paid or hosted infrastructure provisioning.

## Quality Gates

- `npm run check:docs`
- `npm run check:development`
- `npm run check:development-release`
- `npm run check:release-governance`
- `npm run check:all`

## Completion Criteria

- Every planned package has an iteration document.
- Release notes and closure checklists exist for aggregate and final closure packages.
- The development index, decision index, changelog, and manifest reflect Release Governance v1.8.
- `check:release-governance` validates required v1.8 documents and snippets.
- Full repository validation passes before final closure.
