# ADR 0001: Repository First Source Of Truth

- Status: accepted
- Date: 2026-07-17
- Owner: BrandOS maintainers

## Context

BrandOS needs durable repository truth so AI tools and humans can work from the same baseline.

## Decision

Repository First Source Of Truth is accepted for Foundation v0.1.0.

## Consequences

Future work must update repository files and indexes when this decision affects behavior or scope.
