# ADR 0011: Product Core Domain Model

- Status: accepted
- Date: 2026-07-17
- Owner: BrandOS maintainers

## Context

Product Core v0.2 needs stable domain language before design, AI, architecture, and infrastructure work begin.

## Decision

BrandOS Product Core is organized around Workspace, Brand Profile, Evidence, Decision, Workflow,
Context Pack, and Review.

## Consequences

Future releases should map design components, agent context loading, architecture boundaries, and data models
back to these product domains.
