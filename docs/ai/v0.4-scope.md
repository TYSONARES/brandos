# AI Agents v0.4 Scope

## Goal

Define repository-level contracts for BrandOS AI agent behavior before runtime implementation begins.

## In Scope

- Agent role cards
- Prompt contracts
- Context loading rules
- Memory policy
- Evaluation checks
- Output formats
- Safety and refusal rules
- Handoff behavior

## Out Of Scope

- Runtime orchestration
- Model provider selection
- Tool implementation
- Vector database or memory infrastructure
- Production automation

## Definition Of Done

- Agent Card schema and fixture exist.
- Prompt Contract schema and fixture exist.
- Context loading rules are explicit.
- Memory policy rejects chat-only source truth.
- Evaluation checks can validate AI agent readiness.
