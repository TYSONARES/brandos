# Infrastructure v0.6 Scope

## Goal

Define repository-level infrastructure and operations standards before development readiness.

## In Scope

- Environment model
- Deployment target model
- CI/CD release gates
- Observability signal model
- Secret policy model
- Backup and incident response standards
- Release operations

## Out Of Scope

- Cloud provider selection
- Production deployment
- Runtime monitoring vendor selection
- Billing implementation
- Production secrets

## Definition Of Done

- Environment schema and fixture exist.
- Deployment target schema and fixture exist.
- Observability signal schema and fixture exist.
- Secret policy schema and fixture exist.
- Environment, deployment, and observability sets are documented and validated.
- Infrastructure checks are part of `check:all`.
