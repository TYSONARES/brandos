# Incident Response

## Purpose

Incident procedures define how BrandOS responds to release, validation, infrastructure, or operational failures.

## Rules

- Incidents must have severity and owner.
- Promotion stops when release blockers occur.
- Post-incident updates must improve repository standards or checks.

The draft contract is defined in `schemas/incident-procedure.schema.json`.
