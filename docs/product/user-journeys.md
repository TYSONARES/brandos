# User Journeys

## Journey 1: Establish Brand Truth

1. Create a Workspace.
2. Add source material.
3. Draft a Brand Profile.
4. Extract claims.
5. Review and approve the first official profile.

## Journey 2: Prepare AI Context

1. Choose a task type.
2. Select approved brand knowledge.
3. Generate a Context Pack.
4. Review scope and expiry.
5. Use the pack in an AI-assisted workflow.

## Journey 3: Change Strategy Safely

1. Propose a decision.
2. Link evidence and consequences.
3. Request review.
4. Approve or reject the decision.
5. Update affected claims, profile sections, and context packs.
