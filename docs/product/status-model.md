# Status Model

## Object Statuses

### Draft

The object is being authored and is not official.

### Proposed

The object is ready for review but not accepted.

### Approved

The object is official and can be used in active BrandOS workflows.

### Deprecated

The object was once valid but should not be used for new outputs.

### Rejected

The object was reviewed and declined.

## Rule

Approved objects should never depend on rejected, expired, or deprecated context.
