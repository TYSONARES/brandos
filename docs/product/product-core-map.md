# Product Core Map

## System Shape

BrandOS starts with a Workspace. A Workspace contains Brand Profiles, Sources, Claims, Decisions, Reviews,
Workflow Runs, and Context Packs.

## Flow

1. Sources enter the Workspace.
2. Sources support or challenge Claims.
3. Claims become part of a Brand Profile after review.
4. Decisions explain why strategic choices were made.
5. Context Packs package approved knowledge for execution.
6. Reviews protect quality and prevent stale context from spreading.

## Product Boundary

BrandOS is not a generic document system. It is a structured brand operating system where evidence,
decisions, and reusable context are first-class product objects.
