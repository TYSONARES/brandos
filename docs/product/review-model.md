# Review Model

## Purpose

Reviews turn draft brand knowledge into official operating context.

## Review Targets

- Brand Profile
- Claim
- Decision
- Context Pack
- Workflow Run output

## Review Outcomes

- Approved
- Changes needed
- Rejected

## Required Record

Every review should record reviewer, target, outcome, date, and notes.

## Schema

The draft contract is defined in `schemas/review.schema.json`.
