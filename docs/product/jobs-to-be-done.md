# Jobs To Be Done

## Primary Jobs

### Preserve Brand Truth

When a team makes or revises brand decisions, they need a durable place to store the decision, rationale,
evidence, and consequences so future work does not depend on memory.

### Prepare Reliable AI Context

When a person asks an AI agent to help with brand work, they need a scoped, approved context bundle so the
agent does not invent positioning, audience, voice, or constraints.

### Review Strategic Change

When brand knowledge changes, stakeholders need a review path so approved context stays current without
silently rewriting history.

### Translate Strategy Into Execution

When designers, writers, operators, or builders start work, they need clear brand operating context that is
specific enough to guide output and structured enough to be reused.

## Job Quality Bar

A BrandOS job is valid when it has a user, trigger, desired outcome, and product object that carries the result.
