# Release v0.2.0

## Name

BrandOS Product Core

## Status

Complete for repository-level product definition.

## Outcome

Product Core v0.2.0 defines the first durable BrandOS product model. Later releases can now depend on
named domains, object contracts, fixtures, workflow specs, permissions, status rules, and success metrics.

## Included

- Product vision and scope
- Core domains
- Product object model
- Brand Profile model
- Source, Claim, and Decision model
- Context Pack model
- Review model
- Workflow Run model
- Detailed workflow specs
- JSON Schema drafts
- Example fixtures
- Product Core completion decision record

## Release Checklist

- [x] Core domains are named and bounded.
- [x] Product objects have responsibilities and relationship rules.
- [x] Brand Profile, Claim, Source, Decision, Context Pack, Review, and Workflow Run have schemas.
- [x] Fixtures exist for core product objects.
- [x] Workflow specs define trigger, inputs, steps, outputs, acceptance criteria, and failure states.
- [x] Product docs no longer depend on chat-only context.
- [x] Repository checks can validate docs, fixtures, workflows, and release requirements.

## Out Of Scope

- Visual design implementation
- AI agent runtime implementation
- Application architecture
- Infrastructure and deployment
- Production code

v0.3 Design System.
