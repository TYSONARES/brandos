# Workflow Specs

Product Core workflows define how BrandOS product objects move from draft knowledge to approved operating context.

## Specs

- `create-brand-profile.md`
- `verify-claim.md`
- `approve-decision.md`
- `generate-context-pack.md`
- `run-review.md`

## Workflow Rule

Each workflow must define trigger, inputs, owner, steps, outputs, acceptance criteria, and failure states.
