# Create Brand Profile

## Trigger

A Workspace needs its first structured Brand Profile or a new profile version.

## Owner

Brand Owner or Strategist.

## Inputs

- Workspace identifier
- Initial source material
- Owner intent
- Known audience and positioning assumptions

## Steps

1. Create draft Brand Profile.
2. Add positioning, audience, voice, proof points, and constraints.
3. Link available Sources.
4. Convert reusable statements into draft Claims.
5. Mark unresolved assumptions as open questions.
6. Request Review when required sections are present.

## Output

Draft Brand Profile.

## Acceptance Criteria

- Profile has owner, status, and update date.
- Profile includes positioning, audience, voice, proof points, and constraints.
- Claims are linked by identifier.
- Missing evidence is visible as an open question or draft claim.

## Failure States

- No owner assigned.
- Required sections are empty.
- Profile contains unsupported claims marked as approved.
