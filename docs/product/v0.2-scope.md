# Product Core v0.2 Scope

## Goal

Define the first official BrandOS product core: the domains, objects, roles, workflows, and measurable outcomes
that later releases will design, automate, architect, and ship.

## In Scope

- Workspace and brand profile model
- Source evidence and strategy decision model
- Brand memory and context pack model
- Review, approval, and versioning workflow
- Product roles and permissions baseline
- Success metrics for repository-to-product readiness

## Out Of Scope

- Visual design system implementation
- AI agent runtime implementation
- Application architecture and database schema
- Infrastructure, deployment, billing, and integrations
- Public marketing website

## v0.2 Definition Of Done

- Core domains are named and bounded.
- Product objects have clear responsibilities and relationships.
- Primary user journeys are documented.
- Workflows define entry point, output, owner, and acceptance criteria.
- Detailed workflow specs define trigger, inputs, steps, failure states, and acceptance criteria.
- Non-goals prevent premature implementation drift.
- Later roadmap releases can depend on Product Core without chat context.
