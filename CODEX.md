# Codex Operating Instructions

Before making any change in this repository, read these sources completely:

- `README.md`
- `PROJECT_MANIFEST.md`
- `CODEX.md`
- `docs/README.md`
- all directly relevant files under `docs/`

## Prime Directive

This repository is the single source of truth. Do not treat chat history, memory, screenshots, or external
notes as authoritative unless their content has been added to the repository.

## Working Rules

1. Inspect existing files before editing.
2. Prefer small, traceable changes.
3. Update indexes when adding files.
4. Preserve version language and roadmap alignment.
5. Do not invent implementation details that conflict with manifest scope.
6. When a standard is missing, add or update a repository standard instead of relying on assumptions.

## First Message For New AI Sessions

Repository içindeki README.md, PROJECT_MANIFEST.md, CODEX.md ve docs klasörünü tamamen oku. Bundan sonra tüm geliştirmeler bu standartlara göre yapılacak. Bu repository tek doğruluk kaynağıdır.

## Current Release Boundary

Foundation v0.1.0 is about repository readiness. Product runtime, UI implementation, and infrastructure
execution begin in later roadmap releases unless explicitly scoped by a repository decision record.
